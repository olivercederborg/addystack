# Prove it works

**Apply when** you're about to say done, fixed, verified, safe, or "no change needed",
or to rest a decision on a claim.

Check the real artifact, the way its user meets it, before you claim anything about it.

**Why:** "please review the code before answering so confidently".

**Pattern:**
- **UI**: a screenshot of the exact surface and every state you changed, and drive the
  interactions it affects, through the repo's `verify-<app>` skill when it has one.
- **Files**: render every format it ships in, such as PDF and PPTX.
- **Code**: the test or command that fails before and passes after.
- **Claims**: check each one a decision rests on against current code, primary docs,
  or live records.
- **"Safe" or "nothing else"**: name what you read to know it.
- **Gaps**: name each check you couldn't run, and what's still uncertain.

**Tell:** "fixed" with only a typecheck behind it, or a verdict that doesn't say what
was read.
