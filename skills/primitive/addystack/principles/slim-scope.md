# Slim scope

**Apply when** you're shaping a plan, a stack, a review round, or a `Next` list.

Recommend the smallest option that meets the agreed goal, and build its right shape now.
It waits for a one-line follow-up only when someone else owns it, it can't be built yet
(no API, dependency, or design), it dismisses an approval the reviewer didn't ask for,
or the user set the boundary. A draft, no users, or no approvals make now the cheapest
time.

**Why:** "its getting way too out of hand. lets keep it simple" · "but isnt it the best
long term solution ?".

**Pattern:**
- **PRs**: vertical feature slices of up to about 1000 changed lines each.
- **Review loops**: stop at the skill's round cap and list what's still open.
- **Option `a`**: inside the PR's scope, or it names the scope change it makes.

**Tell:** a plan that grew without the user asking, or a follow-up for a change you
called right.
